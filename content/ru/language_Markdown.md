Что такое Markdown?

Markdown — это лёгкий язык разметки, который позволяет форматировать текст с помощью простых символов (например, # для заголовков, _ или * для выделения текста). Он широко используется в науке и IT-сфере благодаря простоте и универсальности.

Основные возможности Markdown
Заголовки: от # до #####
Выделение текста: курсив, жирный, зачёркивание
Списки: маркированные (-, +) и нумерованные (1., 2.)
Ссылки: [Текст ссылки](https://example.com)
Код: bash code или inline code
Цитаты: > Цитата из статьи
Изображения:

Markdown поддерживается почти везде: на GitHub, в редакторах кода (VS Code), в блогах и даже в некоторых системах управления контентом. Это идеальный выбор для написания отчётов, статей и презентаций.
