Что такое управление версиями?

Управление версиями — это процесс отслеживания изменений в файлах и коде, позволяющий легко возвращаться к предыдущим состояниям проекта, сравнивать версии и работать над проектом совместно с другими людьми. Для этих целей чаще всего используется система Git.

Основные понятия Git
Репозиторий (repository) — хранилище всех версий файлов вашего проекта.
Коммит (commit) — фиксированная точка в истории изменений (снимок состояния файлов).
Ветка (branch) — отдельная линия разработки внутри одного репозитория.
Локальный репозиторий — находится на вашем компьютере.
Удалённый репозиторий — размещён на сервере (например, GitHub, GitLab).
Ключевые команды для начала работы
Команда	Описание
git init - Инициализирует локальный репозиторий в текущей папке.
git add . -	Добавляет все изменённые файлы в область подготовки (staging area).
git commit -m - "Сообщение коммита"	Фиксирует изменения с пояснением.
git status - Показывает текущее состояние файлов и веток.
git log -	Выводит историю всех коммитов.
git push origin main - Отправляет ваши изменения на удалённый сервер.

Рекомендуется всегда писать осмысленные сообщения к каждому коммиту (-m), чтобы потом было проще ориентироваться в истории проекта.
